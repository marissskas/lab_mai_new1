Описание программы "In-Memory Database"

Данная программа представляет собой простую базу данных, которая работает полностью в оперативной памяти компьютера. Она позволяет пользователю создавать таблицы для хранения информации, добавлять в них записи, просматривать все сохранённые данные, искать нужные записи по одному или нескольким критериям, изменять и удалять существующие записи, а также сортировать записи по любому полю в порядке возрастания или убывания.

Программа реализована с использованием объектно-ориентированного подхода — вся функциональность заключена в классе Database, который инкапсулирует структуру таблиц и все методы для работы с данными. Код разделён на модули: backend/memory.py содержит основную логику базы данных, tui.py отвечает за текстовый пользовательский интерфейс, а errors.py определяет пользовательские исключения для обработки ошибок.

При запуске программы пользователь видит текстовое меню с девятью пунктами. Для начала работы в программе уже создана демонстрационная таблица под названием "students", которая содержит три записи о студентах с полями: идентификатор, фамилия и имя, возраст и номер группы. Это позволяет сразу опробовать все функции.

Пользователь может создать новую таблицу, указав её имя и перечислив названия колонок через пробел. После создания таблицы в неё можно добавлять записи — программа запросит значения для каждой колонки, и новая запись появится в таблице. Также программа позволяет просмотреть информацию о любой таблице: список колонок и количество записей в ней.

Функция поиска позволяет найти записи, соответствующие заданным условиям. Пользователь может указать значения для любых полей, например, найти всех студентов в возрасте 18 лет или всех людей с определённым именем. Если фильтры не заданы, программа покажет все записи таблицы.

Функция обновления позволяет изменить данные в существующих записях. Сначала пользователь задаёт фильтры, чтобы выбрать нужные записи, а затем указывает, какие поля и на какие значения нужно изменить. Если фильтры не заданы, программа предупредит, что будут обновлены все записи, и запросит подтверждение. Функция удаления работает похожим образом: пользователь задаёт фильтры для выбора записей, подтверждает удаление, и программа удаляет все подходящие записи. При удалении всех записей также требуется подтверждение.

Функция сортировки позволяет упорядочить записи по любому полю таблицы. Пользователь выбирает поле для сортировки и указывает направление — по возрастанию или по убыванию. Сами записи в таблице при этом не изменяются, программа просто показывает отсортированную копию.

Важной особенностью программы является обработка ошибок. Если пользователь пытается создать таблицу с уже существующим именем, создать таблицу без указания колонок, добавить запись с отсутствующим или лишним полем, указать в фильтре или при сортировке несуществующее поле, или обратиться к несуществующей таблице, программа выводит понятное сообщение об ошибке и предлагает продолжить работу без аварийного завершения. Также программа проверяет, что обязательные поля не остаются пустыми при добавлении записи.

Интерфейс программы полностью текстовый и работает через консоль. Пользователь выбирает нужное действие, вводя соответствующую цифру от 0 до 8 (пункт 0 — выход, пункт 8 — информация о таблице), и далее следует пошаговым подсказкам. После выполнения каждого действия программа возвращается в главное меню.

Программа покрыта автоматизированными модульными тестами с использованием фреймворка unittest. Тесты проверяют создание таблиц, все CRUD-операции (создание, чтение, обновление, удаление), сортировку записей, обработку ошибок и работу с несколькими таблицами одновременно. Уровень покрытия кода тестами составляет более 80 процентов.

Требования для запуска программы:
- Python 3.10 или выше

Инструкция для запуска:
1. Нажмите командные клавиши Win+R
2. Перейдите в папку с проектом с помощью команды: cd C:\Users\user\pioa-m7o-113bv-25
3. Введите команду: python -m src.db

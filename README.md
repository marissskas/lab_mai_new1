Описание программы "In-Memory Database"

Данная программа представляет собой простую базу данных, которая работает полностью в оперативной памяти компьютера. Она позволяет пользователю создавать таблицы для хранения информации, добавлять в них записи, просматривать все сохранённые данные, искать нужные записи по одному или нескольким критериям, а также изменять и удалять существующие записи.

При запуске программы пользователь видит текстовое меню с восемью пунктами. Для начала работы в программе уже создана демонстрационная таблица под названием "students", которая содержит три записи о студентах с полями: идентификатор, фамилия и  имя, возраст и номер группы. Это позволяет сразу опробовать все функции.

Пользователь может создать новую таблицу, указав её имя и перечислив названия колонок через пробел. После создания таблицы в неё можно добавлять записи — программа запросит значения для каждой колонки, и новая запись появится в таблице.

Функция поиска позволяет найти записи, соответствующие заданным условиям. Пользователь может указать значения для любых полей, например, найти всех студентов в возрасте 18 лет или все книги определённого автора. Если фильтры не заданы, программа покажет все записи таблицы.

Функция обновления позволяет изменить данные в существующих записях. Сначала пользователь задаёт фильтры, чтобы выбрать нужные записи, а затем указывает, какие поля и на какие значения нужно изменить. Функция удаления работает похожим образом: пользователь задаёт фильтры для выбора записей, подтверждает удаление, и программа удаляет все подходящие записи.

Важной особенностью программы является обработка ошибок. Если пользователь пытается создать таблицу с уже существующим именем, добавить запись с отсутствующим полем или обратиться к несуществующей таблице, программа выводит понятное сообщение об ошибке и предлагает продолжить работу без аварийного завершения. Также программа проверяет, что обязательные поля не остаются пустыми при добавлении записи.

Интерфейс программы полностью текстовый и работает через консоль. Пользователь выбирает нужное действие, вводя соответствующую цифру от 0 до 8, и далее следует пошаговым подсказкам. Выход из программы осуществляется по команде 0.

Требования для запуска программы
 - Python 3.10 или выше

Инструкция дл запуска:
1. Нажмите командные клавиши win+r
2. Перейдите в папку с помощью команды: cd C:\Users\user\pioa-m7o-113bv-25
3. Введите команду python main.py

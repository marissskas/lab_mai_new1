 Система управления базой данных студентов

## Описание программы

Данная программа представляет собой простую систему управления базами данных (СУБД), которая работает в оперативной памяти. Программа предназначена для хранения и управления информацией о студентах. Пользователь может создавать таблицы для хранения данных, добавлять новые записи о студентах, просматривать всех студентов, искать нужных студентов по различным критериям, обновлять информацию о студентаых, удалять записи и сортировать студентов по любому полю. Все данные хранятся в оперативной памяти, поэтому после закрытия программы они не сохраняются. Это делает программу удобной для тестирования и обучения работе с базами данных.

## Архитектура программы

Программа реализована с использованием объектно-ориентированного подхода. Основные компоненты программы расположены в папке backend и включают в себя файл memory.py, который содержит классы Table и MemoryDatabase, а также функции для работы со студентами. Класс Table отвечает за хранение данных одной таблицы и предоставляет методы для вставки, выборки, обновления, удаления и сортировки записей. Класс MemoryDatabase управляет несколькими таблицами и предоставляет интерфейс для работы с ними. Файл errors.py содержит пользовательские исключения для обработки ошибок, такие как ошибка создания существующей таблицы, ошибка обращения к несуществующей таблице, ошибка отсутствия обязательного поля, ошибка использования неизвестного поля, ошибка отрицательного возраста и ошибка дублирующегося идентификатора. Пользовательский интерфейс реализован в файле tui.py и представляет собой консольное меню с командами для выполнения всех операций. Точка входа в программу находится в файле __main__.py. Тесты расположены в папке tests и написаны с использованием фреймворка unittest. Они проверяют создание таблиц, вставку записей, выборку с фильтрами, обновление, удаление, сортировку и обработку ошибок.

## Функциональные возможности

Программа предоставляет следующие возможности. Создание таблицы позволяет пользователю задать имя таблицы и список колонок. По умолчанию предлагаются стандартные поля для таблицы студентов: id, имя, фамилия, возраст и пол. Добавление студента требует указать значения для всех колонок таблицы. Программа проверяет, что все обязательные поля заполнены, и что нет лишних полей, не предусмотренных структурой таблицы. Возраст не может быть отрицательным. Просмотр всех студентов выводит список всех записей в таблице в виде форматированной таблицы с колонками ID, Имя, Фамилия, Возраст и Пол. Поиск студентов позволяет найти записи по одному или нескольким критериям. Пользователь вводит значения полей для поиска, а программа выводит все записи, соответствующие заданным фильтрам. Фильтры работают по принципу точного совпадения. Обновление данных студента позволяет изменить значения полей в существующих записях. Сначала пользователь задаёт фильтры для выбора записей, которые нужно изменить, а затем указывает новые значения для нужных полей. Если фильтры не заданы, обновляются все записи. Удаление студента удаляет записи, соответствующие заданным фильтрам. При удалении всех записей без фильтров программа запрашивает подтверждение. Сортировка позволяет упорядочить записи по любому полю таблицы в порядке возрастания или убывания. Сортировка не изменяет исходные данные, а только показывает отсортированную копию. Информация о таблице выводит список колонок и количество записей в выбранной таблице.

## Обработка ошибок

Программа корректно обрабатывает следующие ошибочные ситуации. При попытке создать таблицу с именем, которое уже существует, программа сообщает об ошибке. При обращении к несуществующей таблице выводится соответствующее предупреждение. При добавлении записи с отсутствующим полем программа сообщает, какого поля не хватает. При добавлении записи с лишним полем программа сообщает, какое поле неизвестно. При попытке добавить студента с отрицательным возрастом программа выводит сообщение об ошибке. При попытке добавить студента с идентификатором, который уже существует в таблице, программа сообщает о дублировании. При использовании несуществующего поля в фильтрах или сортировке программа выводит сообщение об ошибке.

## Интерфейс пользователя

Программа имеет текстовый консольный интерфейс. При запуске отображается главное меню с десятью пунктами от 0 до 9. Пользователь вводит номер команды, после чего программа выполняет соответствующее действие. Все действия сопровождаются понятными подсказками и запросами на ввод данных. После выполнения каждой операции программа возвращается в главное меню. Выход из программы осуществляется по команде 0.

## Установка и запуск

Для работы программы требуется Python версии 3.10 или выше. Никаких дополнительных библиотек не требуется, так как используются только встроенные модули. Для запуска программы необходимо открыть командную строку, перейти в папку с проектом и выполнить команду python -m src.db. После этого отобразится главное меню программы.

## Запуск тестов

Для запуска тестов необходимо установить библиотеку coverage командой pip install coverage. Затем выполнить команду coverage run -m unittest discover tests для запуска всех тестов и сбора информации о покрытии. После этого можно посмотреть отчёт о покрытии командой coverage report -m. Уровень покрытия кода тестами составляет более 80 процентов, что гарантирует надёжность работы основных компонентов системы.

## Структура проекта

Проект организован следующим образом. В корневой папке находится файл README.md с описанием проекта. Папка src содержит исходный код программы. В папке src/db находятся файлы __init__.py, __main__.py и tui.py. Файл __main__.py является точкой входа и запускает приложение. Файл tui.py содержит класс DatabaseApp с реализацией текстового интерфейса. Папка src/db/backend содержит файлы __init__.py, errors.py и memory.py. Файл errors.py определяет пользовательские исключения. Файл memory.py содержит классы Table и MemoryDatabase, а также функции create_record, select_record, init_student_table и класс Student для обратной совместимости с первой лабораторной работой. Папка tests содержит файлы __init__.py и test_memory.py с модульными тестами.
